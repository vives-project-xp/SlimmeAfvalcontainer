# Two-stage training outputs

Deze map bevat in GitHub geen zware trainingsbinaries, maar wel de verwijzing naar de juiste downloadlocatie.

## Bestanden

De echte trainingoutputs zijn:

- `stage1_main.pth`
- `stage2_overige.pth`
- `stage1_main.onnx`
- `stage1_main.onnx.data`
- `stage2_overige.onnx`
- `stage2_overige.onnx.data`
- `two_stage_metadata.json`

## Download

Download deze via:

[Smart Bin Model Artifacts](https://www.kaggle.com/datasets/maartenaudenaert/smart-bin-model-artifacts)

In die Kaggle dataset zit een tarbestand `two_stage_training_outputs.tar` met daarin:

```text
two_stage_training_outputs/
|-- stage1_main.pth
|-- stage2_overige.pth
|-- stage1_main.onnx
|-- stage1_main.onnx.data
|-- stage2_overige.onnx
|-- stage2_overige.onnx.data
`-- two_stage_metadata.json
```
